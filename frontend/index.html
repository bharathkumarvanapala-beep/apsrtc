🛰️ APSRTC Multi-Bus GPS Telemetry Simulator Lab

Dev / Demo Mode

This prototype incorporates an automated multi-bus GPS simulator that pushes realistic telemetry along the Araku-Visakhapatnam ghat corridor with speeds, headings, and distinct sources.

In-Browser Quick Simulation Controls

You can trigger telemetry pings directly from your browser to keep signals fresh and watch real-time WebSocket pulses on the Passenger Portal and Map.

# Standalone Background Simulator Command
To run the continuous multi-bus background simulator in a separate terminal:
cd backend
npm run simulate
Simulates 7 buses across Eastern Ghats corridors via HTTP REST endpoints (/api/v1/tracking/*).
